# Wasabi Japanese Restaurant website

Static HTML / CSS / JavaScript (no framework). Prototype stage.

## Pages
`index.html`, `lunch-menu.html`, `dinner-menu.html`, `about.html`, `contact.html`

## Before going live
- Add prices to `menu-data.js` (none are included on purpose) and remove the "Prices will be added here." line in `tools/build_pages.py`.
- Replace the placeholder About Us text with the owner's story.
- Remove the `noindex` line from `tools/build_pages.py` (it keeps search engines from listing the prototype), then run `python tools/build_pages.py`.
- Photos were cut from screenshots of the old site; replace them with originals if available (same file names in `images/`).

## Editing
Pages are generated by `python tools/build_pages.py` (needs Python 3). `menu-data.js` holds the menu text.
`tools/build_menu_data.py` rebuilds `menu-data.js` from the restaurant's menu spreadsheet (not included here).

## Publishing
GitHub Pages: Settings > Pages > Deploy from branch > `main` / `(root)`.
